# صندوق الجمعية

تطبيق ويب للجوال لإدارة صندوق جمعية عائلية: أعضاء، اشتراكات شهرية، مصروفات، والرصيد المتوفر.

البيانات تُحفظ على الجوال فقط. ملفات GitHub هي الواجهة الفارغة.

## التشغيل على الماك

```bash
npm install
npm run dev
```

افتح الرابط في المتصفح للتجربة.

## الرفع على GitHub Pages (رابط للجوال)

1. أنشئ مستودعاً فارغاً على GitHub وادفع هذا المشروع على فرع `main`.
2. من إعدادات المستودع: **Pages** → المصدر **GitHub Actions**.
3. بعد نجاح الـ Action يصير الرابط:
   `https://اسمك.github.io/اسم-المستودع/`
4. من **سفاري** على الآيفون افتح الرابط → مشاركة → **إضافة إلى الشاشة الرئيسية**.

## نسخة احتياطية

من الإعدادات: تصدير نسخة، أو مشاركة عبر واتساب، ثم استيراد الملف عند الحاجة.
